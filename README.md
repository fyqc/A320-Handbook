## 🇨🇳 中文说明 <a id="-中文说明-chinese"></a>

### 📖 项目背景
原版的 **Tech Mobile** 网站在日常工作中提供过极大的帮助，尤其是其中的 **Reset (ATA List)** 功能，在现场排故时解决过无数的实际问题。然而，由于种种原因，原网站自去年起不再可用，甚为遗憾。

为了延续这份便利，并帮助海内外广大同行，本项目对该网站进行了完全的重构与现代化适配，打造出一个轻量、无广告、100% 完整可用的静态速查工具，方便大家在移动端或电脑前随时查阅。

### 🛠️ 主要功能
*   **🔄 Resets (ATA List)**：涵盖各 ATA 章节的跳开关与复位程序表格。
*   **🔤 Airbus Acronyms**：常用航空缩写与专业术语速查。
*   **📢 Airbus Alpha Call Ups**：AIDS 动态/静态参数 Alpha Call-Up 代码及参数说明（附带实时搜索）。

### 🚀 免责声明
本仓库内容仅供**航空技术参考与培训学习使用**（For Reference / Training Only），不得用于实际航班放行或正式维修签字凭证。

## 🇬🇧 English Description <a id="-english-description-english"></a>

### 📖 Background
The original **Tech Mobile** website was an incredible tool for our daily work, especially the **Reset (ATA List)** section, which helped countless technicians resolve troubleshooting issues on the line. Unfortunately, for reasons unknown, the original site went down last year, leaving a huge void.

To preserve this valuable resource and support our fellow technicians, this project is a modern, lightweight, and fully functional rewrite of the original site, optimized for quick mobile and desktop reference.

### 🛠️ Key Features
*   **🔄 Resets (ATA List)**: Circuit breaker and reset procedure tables organized by ATA chapters.
*   **🔤 Airbus Acronyms**: Quick reference for common aviation acronyms and technical terms.
*   **📢 Airbus Alpha Call Ups**: AIDS parameter Alpha Call-Up codes and descriptions with real-time search support.

### 🚀 Disclaimer
This repository is for **reference and training purposes only** and must not be used for official aircraft sign-offs or line maintenance execution.
